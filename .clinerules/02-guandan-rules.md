# 掼蛋规则（淮安标准，Phase 02 生效）

## 基础
- 两副牌 108 张，4 人 2v2
- 牌点：大王>小王>级牌>A>K>Q>J>10>9>8>7>6>5>4>3>2
- 红桃当前级牌 = 逢人配（可配除王外任意牌）

## 牌型
单张 / 对子 / 三张 / 三带二 / 顺子(=5) / 连对(=3对连续) / 飞机(=2组三张连续) / 同花顺 / 炸弹(≥4同点) / 天王炸(4王)

## 大小关系
- 非炸弹之间按牌型同结构比最大牌点
- 炸弹压一切非炸弹；炸弹比张数，同张数比点
- 同花顺算炸弹级，可压普通炸弹（按规则定级，先按“同花顺=同张数炸弹”实现）
- 6张及以上炸弹可以压同花顺
- 天王炸最大

## 流程
- 发牌：每人 27 张，随机发牌
- 进贡：末游向头游进最大单牌，头游还一张≤10的牌；双下时双贡
- 接风：玩家出完最后一张且无人压，队友接风
- 升级：头游二游同队 +2级；头游三游 +1级；打A需头游且非末游过关
