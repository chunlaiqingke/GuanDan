# AI 能力规范（Phase 04~05 生效）

## AI 分层
1. **规则层（Phase 02 已完成）**：纯函数判断合法出牌集合
2. **决策层（Phase 04）**：服务端 C++ 启发式策略
3. **提示层（Phase 04）**：复用决策层，给真人返回 Top3 推荐出牌
4. **教学层（Phase 05）**：出牌附带 reason_tag，客户端弹讲解

## 决策策略（不接大模型）
- 手牌拆牌评估：按“最小手数”拆牌
- 出牌优先级：
  1. 能走完优先走
  2. 压对手大牌时优先用最小可压牌
  3. 保留炸弹给关键回合
  4. 队友头游领先时主动让牌（过）
  5. 对手快走完时优先堵单张/对子
- 难度档：简单(随机合法)/普通(启发式)/困难(带记牌器+队友配合权重)

## 提示出牌接口
- C2S_Hint → 服务端算合法可出集合 → 按策略排序返回 Top3
- 客户端高亮对应牌

## 教学能力
- 每次 AI 出牌/提示，服务端附 `reason_tag`：
  `beat_last` / `min_beat` / `save_bomb` / `let_teammate` / `block_opp` / `go_out`
- 客户端根据 tag 显示白话讲解，如“用最小对子压住，保留炸弹”
- 后续可选：客户端把 tag+上下文发给 LLM 生成自然语言教学（Phase 05 后期）

## 禁止
- 不在客户端算 AI 决策
- Phase 04 前不引入任何 LLM/HTTP 外调
